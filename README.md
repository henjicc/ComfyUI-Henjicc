# ComfyUI-Henjicc

ComfyUI 自定义节点包，提供图片、视频、音频素材输入、参考图处理、尺寸计算、提示词助手及音频混音，并增强原生 LoadImage 的资源选择界面。

仓库只维护节点实现、配套前端、翻译、依赖声明、开发规则和必要测试。个人工作流、素材、生成结果、录制记录、模型选型及宿主环境维护资料不随节点包分发。

## 安装

将本仓库放入 ComfyUI 的 `custom_nodes/ComfyUI-Henjicc`，使用该 ComfyUI 的 Python 环境安装 [pyproject.toml](pyproject.toml) 声明的依赖，然后重启 ComfyUI、刷新页面。无需 npm 安装或前端构建。

本包基础节点要求 Python 3.10 或更高版本，使用 ComfyUI V3 节点接口 `comfy_api.latest`。ComfyUI、PyTorch 和匹配的 torchaudio 由宿主提供，不要使用插件安装过程替换宿主计算环境。依赖声明不代表已验证所有平台及宿主版本；可选功能还须满足其依赖包的 Python 要求。

Qwen2.5-Omni 助手另需 `omni` 可选依赖组及完整本地模型，其他节点不因此需要该模型。模型、第三方节点和权重不随本包提供，不会在注册节点时自动下载安装。

## 节点

节点名称与界面跟随 ComfyUI 的中文 / 英文设置；中文品牌为“痕继痕迹”，英文为“Henjicc”。内部 ID、用户提示词、素材名称和标签不随语言改变。

| 节点 | 内部 ID | 职责 |
|---|---|---|
| 超级输入 | `HenjiccSuperLoader` | 图片、视频、音频、稳定素材引用及提示词预设 |
| 参考图处理 | `HenjiccQwenReferenceList` | 有序 IMAGE 列表、逐图尺寸预算、首张原图和提示词 |
| 图片列表分配 | `HenjiccImageListToSlots` | 一次聚合 IMAGE 列表或 batch，分配至十个标准 IMAGE 接口 |
| 尺寸画板 | `HenjiccResolutionBoard` | 预设、参考图或手动尺寸，比例、对齐及像素预算 |
| MiniMax H3 素材适配 | `HenjiccMiniMaxMedia` | 调用宿主原生参考生视频或首尾帧条件接口 |
| MiniMax H3 角色替换素材 | `HenjiccH3RoleInputs` | 准备参考图、视频时序及模型帧数 |
| MiniMax H3 成片时序 | `HenjiccH3VideoOutput` | 按原生 24 fps 同步裁切生成画面和音轨，输出 VIDEO |
| Qwen2.5-Omni 多模态提示词助手 | `HenjiccOmniPrompt` | 联合理解图片、视频和音频，输出 STRING |
| Qwen3-VL 提示词优化助手 | `HenjiccVisualPrompt` | 原图与视频拼图理解，输出文本、IMAGE 列表及更新提示词的素材 |
| 人声与伴奏混音 | `HenjiccAudioMix` | 标准 AUDIO 的增益、手动偏移、长度及峰值处理 |

注册清单以 [__init__.py](__init__.py) 的 `get_node_list` 为准。模型加载、量化、采样、音频分离和音色转换由对应原生或第三方节点负责。

## 资源库与超级输入

原生 LoadImage 的“资源库”按钮增强前端选图，不替换其后端和 IMAGE / MASK 输出。设置入口为“设置 → 痕继痕迹 → 资源库”，可关闭增强并恢复原生选择控件。

资源库浏览宿主配置的 input、output、temp，支持按文件名或标签搜索、排序、评分、批量标签及预览。图片和视频默认隐藏文件名；音视频悬停播放、双击预览、缩略图显示及单击使用行为可在设置中调整。

input 支持上传且不覆盖同名文件；删除须确认，执行后永久删除原素材。output 和 temp 仅浏览，选用时复制到 input 的 `henjicc/imports`，源文件保留。评分和标签按来源分别保存在宿主当前用户目录的 `henjicc/image-library*.sqlite3`，音频波形缓存在 `henjicc/cache/waveforms`。移动文件不会自动迁移元数据。

超级输入可通过上传、剪贴板、资源库或拖放添加素材。替换只接受同类型素材，保留条目 ID、顺序、启用状态及引用；移除条目不删除源文件。点击缩略图打开查看器，支持前后切换及音视频播放；拖动或 Alt+方向键调整顺序。

提示词中输入 `@` 或点击素材编号插入稳定引用，也可手写 `图片1`、`<image1>` 等标签。排序后编号随素材更新；删除素材造成的失效引用会阻止执行，不会自动指向其他素材。视频原声默认关闭，启用后才参与音频编号；没有音轨时明确报错。

模型模式沿真实下游连接识别。单接通用参考图处理保持通用模式；接原生千问编码器识别千问，接 MiniMax 适配识别 MiniMax。MiniMax 的参考 / 首尾帧任务仍显式选择。同时接不同模型会报错，应分别使用超级输入。

- 通用素材状态最多 24 项，只接受宿主 input 内相对路径；每文件最多 512 MiB，序列化状态最多 1 MiB。
- 千问链路仅接受图片，最多十张；MiniMax 参考链路最多九图、三视频、三独立音频，合计十二项。实际限制由对应节点再次校验。
- MiniMax 首尾帧支持零至两张图，均按目标画布等比补边；参考视频和音频具有时长、解码及像素预算限制，超限明确报错。
- IMAGE batch 与宿主 IMAGE 列表语义不同。参考图处理保留独立尺寸与顺序；多个参考槽共同参与一次生成时，使用图片列表分配一次聚合，避免变成逐图生成。

## 尺寸与提示词

超级输入的预设管理提示词和可选尺寸，不管理模型或采样参数。自定义预设随节点属性保存；清除预设保留素材和提示词，解除尺寸绑定。将“预设尺寸”接到尺寸画板即可跟随；断线或无有效预设时使用画板自身设置。

尺寸画板支持参考图比例、手动尺寸、锁定比例、横竖交换、常见比例及对齐倍数，像素预算作为上限。已知输入链可在运行前预览原始尺寸，未知图像变换等待实际执行。前端预览与后端执行共用尺寸规则；项目安全上限不等于模型官方硬上限。

Qwen3-VL 助手接收宿主 CLIP 加载器提供的完整模型，忽略音频及视频原声。视频按真实时间戳分段抽帧拼图，覆盖完整时段并受总像素预算约束；这是图片输入路径，不是原生视频时序推理。文本生成需要完整语言模型，缺少输出头的专用条件编码器会被拒绝。自动任务按下游连接解析，自定义任务需填写要求；输出素材保留 ID、音频和预设，仅更新提示词。

Qwen2.5-Omni 助手支持本地 `Qwen2.5-Omni-3B` / `Qwen2.5-Omni-7B`，模型放在宿主模型根目录的对应 `LLM/` 子目录，包含 `spk_dict.pt` 等完整配套文件。使用 BF16 和 Transformers SDPA，仅读本地模型；视频及音频分析开头 1–15 秒。输出需人工核对，推理成功不代表描述或改写准确。

人声与伴奏混音按伴奏时长补齐或截断人声，支持两路增益和正负时间偏移、限制峰值；不自动识别拍点或调整旋律速度。

## 源码目录

根目录 `__init__.py` 是 ComfyUI 扩展入口，显式导入并注册各分类节点，`WEB_DIRECTORY` 仍指向 `web/`。Python 实现按职责分包，目录调整不改变节点 ID、界面分类和工作流输入输出。

| 目录 | 内容 |
|---|---|
| `image/` | 图片列表处理、分配、预设及尺寸画板 |
| `media/` | 超级输入、素材引用与 MiniMax 条件适配 |
| `video/` | 视频预处理及 MiniMax H3 成片时序 |
| `audio/` | 人声与伴奏混音 |
| `text/` | Qwen2.5-Omni 和 Qwen3-VL 提示词助手 |
| `library/` | 资源访问、评分标签及音频波形 |
| `web/`、`locales/` | 前端资源及中英文翻译 |
| `tests/` | 节点和前端回归测试 |

## 开发与验证

- [项目上下文](rules/project-context.md)：模块入口与实现约束。
- [AGENTS.md](AGENTS.md)：协作范围、开发规则及按需读取入口。
- [pyproject.toml](pyproject.toml)：Python 要求及依赖的权威来源。
- `tests/`：合成数据和最小执行图构成的节点回归测试，不依赖个人工作流。

在项目根目录，将实际 ComfyUI 根目录加入 `PYTHONPATH`，使用该宿主的 Python 环境运行后端测试；前端测试使用 Node.js：

```text
<ComfyUI Python> -m unittest discover -s tests -v
node --test tests/*.test.mjs
```

Python 实现变更需要重启对应宿主，前端变更需要刷新页面；翻译文件由宿主缓存，修改后需要重启。集成验证先确认宿主加载的是当前工程，再检查节点注册和最小输入输出；不为测试启动模型生成、修改用户工作流或升级宿主依赖。

资源库接受回环及局域网 IP 同源请求，拒绝公网、跨源和越界路径；地址范围限制不是账户鉴权，实际网络暴露由宿主部署决定。供应商凭据、个人路径、私有素材及生成历史不得进入代码、测试或导出数据。
