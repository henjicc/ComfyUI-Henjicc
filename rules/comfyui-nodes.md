# ComfyUI 节点开发与联调

> 读取时机：实现或迁移节点、注册与数据契约、调用执行 API、准备节点打包时读取相应章节；控制宿主前必读控制操作规程。

## 开发范围与注册

- 本仓库只开发节点包。最小测试图用于验证本包能力，不演变为个人工作流、模型配方、宿主维护或第三方补丁的交付目录。
- 严格遵守 [节点编写权限与解决顺序](../AGENTS.md#节点编写权限与解决顺序)：先核查原生及已安装第三方节点的真实能力与可组合方式，再查可用第三方方案；已有方案可满足目标时不新增节点。无可行方案时说明具体缺口，等待用户决定，不以适配或包装名义自行新增。
- 只有用户明确要求编写节点时才进入实现。采用 V3 `io.ComfyNode`、`define_schema`、`io.Schema` 与 `io.NodeOutput`，通过 `comfy_entrypoint` 返回 `ComfyExtension`；注册清单以根 `__init__.py` 为准。参考 [V3 文档](https://docs.comfy.org/custom-nodes/v3_migration)。
- 当前使用 `comfy_api.latest`，实施时核验目标宿主的实际公共接口；编号接口不自动代表稳定契约。不要同时导出会遮蔽 V3 入口的旧 `NODE_CLASS_MAPPINGS`。
- ID 默认以 `Henjicc` 为前缀，分类在 `Henjicc/` 下。通用节点按能力命名，模型绑定节点写完整模型名称；显示名与内部 ID 分离。输入名、输出顺序和类型是已保存图的契约，不能随展示改名破坏。
- 注册只做明确导入和声明，不吞掉导入错误，不启动服务、下载模型或安装依赖。不用实例构造器或可变类属性跨执行保存任务与令牌。

## 数据、执行与缓存

- 优先使用宿主标准 IMAGE、MASK、AUDIO、VIDEO、LATENT、CONDITIONING 等类型。自定义类型必须表达当前必要的跨媒体引用或可选尺寸语义，不仅用于少接几条线。
- IMAGE 通常为 `[B,H,W,C]`，MASK 为 `[B,H,W]`，按目标宿主核验值域、通道、dtype/device 与尺寸策略，不原地修改共享输入。LATENT 保留其字典语义及附加字段。
- tensor batch 与 [数据列表执行](https://docs.comfy.org/custom-nodes/backend/lists) 不同。异尺寸图片保持独立比例与顺序；列表接普通节点可能逐项执行，需要共同参考时明确聚合并分配到模型独立槽，不隐式裁剪、丢图或改变生成次数。
- schema 与执行签名一致，静态校验不做昂贵计算或网络请求，运行时仍校验上游数据。隐式输出映射、动态插槽和虚拟路由需核对宿主实际导出图，不只验证手写 API 图。
- `fingerprint_inputs` 返回缓存指纹。文件变化、连接派生状态、随机和外部调用分别定义缓存语义，不对所有节点一律禁用缓存；`not_idempotent` 不能当作跨运行只调用一次或计费幂等保证。
- 凭据不进入普通 widget、提示词、前端或导出数据。第三方供应商调用不默认使用宿主 Comfy 账户令牌，不因存在外部请求就设置 `is_api_node=True`。
- 普通计算节点不新增 HTTP 路由；有必要时使用包专属命名空间，校验来源、路径、请求大小及权限，遵循 [安全规则](security.md)。

## 控制操作规程

本节只适用于本包安装、联调和验收所需的宿主操作。个人工作流整理、模型下载、生成制作和宿主维护不因这些规程而获得授权。纯文档和规则变更无需启动宿主。

### 操作前检查

1. 从实际安装目录、启动配置或现有页面发现宿主地址与解释器，不在仓库写入个人绝对路径、固定实例编号或会话 ID。
2. 查询目标的 `GET /system_stats`、`GET /queue`，结合监听进程命令、工作目录和父链确认实例归属；同名目录或在线端口不能证明加载了本工程。
3. 需要修改画布时，先核对目标页面、活动工作流及未保存状态。使用 MCP 时实际发现工具、确认桥健康及目标会话，再通过只读查询核对工作流身份；同源标签可能共用会话 ID，不能任意选择在线页面。
4. 保留用户队列、未保存画布、全局历史、素材和其他节点。测试使用独立临时图及合成数据，不覆盖个人工作流。

### 入口选择

| 入口 | 适用任务与边界 |
|---|---|
| 原生 HTTP API / WebSocket | 节点、模型枚举及执行结果查询，最小图提交与进度追踪；不能代表活动浏览器画布 |
| 已连接且核验过的 MCP | 活动画布读取、参数修改及执行图导出；实际发现工具及会话后使用，不从配置存在推断可用 |
| 内置浏览器 | 动态控件、前端导出、真实界面验收及交付展示；保护原有画布，不通过私有状态伪装操作 |
| 临时测试图 / 文件 | 准备隔离的回归输入；写入文件不等于活动画布已更新，UI 图与 API 图的语义分别核验 |

MCP 不可用时，能用 API、文件或内置浏览器完成的部分继续执行。不能为兜底自写控制插件、节点或 MCP 服务；也不把安装控制桥变成节点开发的默认前置条件。

### 启动、重启与冲突

- 优先复用正确的已运行实例。确需联调且服务未启动时，主动通过已核验的宿主管理器或现有启动入口持久启动，完整保留解释器、端口、模型配置及 input/output 参数，不另建实例或手改生成配置。
- 缺少可靠启动参数时继续静态与隔离验证，并指出用户需要提供的最小入口，不猜启动命令。Desktop 管理的实例不由其他 CLI 接管。
- Python 变更需要重启时，先核对归属及队列为空；有用户任务时不擅自中断。只有确认相应管理器支持且当前实例受其管理时，才用其重启接口；否则按已核验的完整启动参数受控重启。
- 仅前端变化刷新页面；翻译缓存按宿主实际机制重启。刷新前保护未保存内容。桥接异常只修复已确认归属的桥，不同时重启正常宿主。
- 端口占用先确认 PID 和归属；正确实例复用，其他程序不得擅自结束，不能静默换端口另开实例。停止进程必须针对明确目标，不能按 python/node 名称批量终止。
- 启动或重启后重新核验 `/system_stats`、本包注册、队列、监听归属及必要日志；涉及画布桥时再核对页面连接和只读调用。断连、进程出现或短暂日志不代表成功。
- 所有可行入口均不能完成时，停止受阻部分并说明具体错误、已完成准备和用户最少需要执行的步骤，不把静态校验说成运行成功。

### 执行与结果

- 先核对实时 `/object_info` 和目标宿主源码，再使用原生执行 API；参考 [路由](https://docs.comfy.org/development/comfyui-server/comms_routes) 与 [消息协议](https://docs.comfy.org/development/comfyui-server/comms_messages)，不套用云端 API。
- 动态插槽或子图连接需由实际前端导出并核验关键参数；UI 图保留控件和布局，API 图反映执行。隔离测试图使用独立图及子图身份，不和用户图共享定义。
- 提交前连接 WebSocket，使用独立 client_id / prompt_id，检查 error / node_errors。排队、`executed` 消息或预览恢复不能代替执行成功；断连后先查自己的任务历史，不重复提交生成。
- 只取消获授权的目标任务，先核验当前宿主是否有按 ID 取消入口；不回退到全局中断、清队列或清历史。不为注册和 UI 检查自动加载模型或运行完整采样。
- 安装、导入、注册、前端识别和真实执行分别验证。模型枚举不等于模型可用，媒体可解码不等于适配或质量已验证。

## 安装、依赖与打包

- 核对 `custom_nodes` 安装或联接的真实目标，不覆盖同名旧包；Python 使用实际宿主环境，前端资源由 `WEB_DIRECTORY` 提供。
- 依赖只在 `pyproject.toml` 维护，ComfyUI、torch/CUDA 和宿主生成配置不由插件升级。可选功能延迟加载依赖；核验目标 Python ABI、操作系统及架构，不混用二进制包。
- 发布元数据和许可证仅填写已确认事实，发布、部署与历史改写按独立授权处理。参考 [Registry 规范](https://docs.comfy.org/registry/specifications) 和 [安全标准](https://docs.comfy.org/registry/standards)。
- 不在导入或执行期间安装 Python/npm 依赖，不使用代码混淆或执行任意外部代码，不干扰其他节点。
- 分发只包含节点开发文件，不带个人工作流、素材、模型、生成结果、缓存、账户配置或宿主补丁。新增可复用示例需用户明确要求并使用合成数据，不默认恢复个人使用资料。
