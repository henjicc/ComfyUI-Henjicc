# 节点界面、宿主扩展与文案

> 读取时机：修改界面、样式、文案或交互时；只应用与本次变化相关的条款。

## 沿用宿主界面

- 优先用节点 schema 与 ComfyUI 原生 widget 表达输入、输出及预览，不为普通参数新增前端工程或组件库。
- 确需 JavaScript 扩展时，通过包的 `WEB_DIRECTORY` 暴露资源，以唯一扩展名调用 `app.registerExtension`；按实际需要使用公开 hooks、设置、菜单与提示 API。参考 [官方扩展入口](https://docs.comfy.org/custom-nodes/js/javascript_overview)，操作前核对本机前端版本。
- 复用宿主主题与控件，CSS 限定在本包范围；不修改其他节点原型、依赖 DOM 私有结构或全局覆盖样式。事件监听与资源有对应清理路径，前端刷新不重复注册副作用。
- 已授权的 LoadImage 注入仅操作该类节点实例：保留原始 image 值、序列化及预览回调，通过原生 button widget 打开图片库；关闭设置恢复原控件。不能重新采用旧项目覆盖后端 LoadImage 或全局 ContextMenu 的做法。节点设置同步包括子图，不重置用户已有节点尺寸。
- 宿主原生图片选项可能只列 input 顶层文件，前端缺失检查依赖该列表；工作流重载时先核验子目录选图确实存在，再补入实例选项，不能无条件加入序列化值而掩盖真正缺失。
- 后端执行不能依赖浏览器回调完成；前端不持有供应商秘密。改变输入序列化或执行链路时验证无浏览器的 API 工作流，纯标签和样式修改按风险做局部验证，具体边界见 [节点规则](comfyui-nodes.md)。

## 布局、层级与主题

- 间距表达关系；组件管理内部间距，父布局管理组件之间的间距，避免重复留白。
- 节点布局保持画布所需密度，按宿主缩放、节点宽度与长标签验证；仅在真实面板需求出现时考虑面板响应式布局。
- 素材与提示词等 DOM 控件使用宿主分配的尺寸，设内容所需的最小高度并在内部滚动，不以固定高度或最大高度阻止节点伸缩。定制控件分别跟随经典画布与 Nodes 2.0 的宿主主题；验证主题/渲染模式切换、缩小/放大和保存重开。视图挂载身份不持久化，撤销重建节点后必须显示并操作当前实例，不能停留在已释放的旧控件。
- 不用空白字符、重复换行、无意义占位或不断增大 z-index 修补布局。
- 优先用间距和排版分组，必要时用分隔线或容器；不堆叠卡片、边框、阴影和无目的动效。
- 跟随宿主主题，不增加独立主题系统；状态不能只靠颜色表达。
- 自绘提示词与素材引用沿用宿主默认界面字体，不写死等宽字体而使中文回退为宋体；超级输入自动识别连接的模型，仅 MiniMax 任务选择使用跟随宿主主题的自定义浮层，保留键盘选择、外部点击关闭及窗口边缘避让。
- 节点面板初始化与素材 ID 创建须兼容 HTTP 局域网地址；使用 `web/identity.js`，不能直接依赖仅安全上下文可用的 `crypto.randomUUID()`。图片库已获授权支持局域网 IP 同源访问，使用当前宿主相对 API 地址，不硬编码 localhost；来源与文件路径校验由服务端执行。

## 本包素材与节点交互

- 本包参考图处理优先提供一个标准 IMAGE 图片列表出口，增减素材无需重连，不在主画布展开十个图片接口。需要共同参考时，在模型内部一次聚合列表并分配到独立槽，不能为减少连线退回私有图片组或改变生成次数。移除/清空当前列表不删除磁盘原文件；永久删除仍使用图片库已有确认与权限边界。上传、选中节点粘贴、排序、启用、撤销和重开只覆盖本次受影响行为。
- 超级输入使用统一的缩略图与放大查看交互：不显示文件名，完整保留画面，左上角编号叠在素材上；操作用悬停/键盘聚焦图标，触屏保留可达入口，停用状态不只靠颜色。单击或键盘打开统一查看器并快速切换；替换保留原位置和稳定引用。普通素材卡片不恢复底部一排文字按钮或文件信息。
- 提示词中的稳定素材引用以小方形缩略图和编号呈现，`@` 选择浮层与文字插入位置对齐并包含缩略图/名称；窗口边缘可避让。不能以节点底部固定菜单替代，也不能让浮层继承画布缩放或被节点滚动裁掉。键盘、IME 组合、撤销及重开保持引用数据格式与身份，视图资源随节点清理。
- 自绘面板的状态编辑沿用宿主原生控件的历史事务：当前前端使用配对的 `canvas.emitBeforeChange/emitAfterChange` 与 graph 回调，不能只靠被面板截断的鼠标事件兜底。内容编辑器阻止浏览器原生撤销争抢宿主历史，不额外执行一次 Undo；分别核对经典画布和 Nodes 2.0 的实际数据及恢复界面。
- 会改变后续操作或执行的用户选项必须存入节点 widget 或 properties，不能仅存在面板实例中；包括尺寸画板的锁定／自由比例。恢复、撤销和重做均从节点保存状态读取，验证实际工作流文件及重开后的控件；菜单展开、悬停、播放器等临时界面状态不持久化。
- 输入预算与输出画布分开：图片缩放保持比例，当前图片参考预算优先 Lanczos，不自动拉伸或裁剪，模型网格对齐的舍入明确核验；明确要求裁剪时再裁范围。保留首图、自定义尺寸、百万像素或倍率等方式仅在当前需求及模型契约内提供，不给所有节点机械增加全套选项。
- 模型可可靠区分有效素材时优先自动文生图/编辑切换；角色卡等版式仍独立控制，不能套用于必须手动选择任务的模型。实际模式判断及多图语义按 [节点规则](comfyui-nodes.md)。

## 文案与说明

- 本项目支持中文和英文，跟随宿主 `Comfy.Locale`。中文品牌为“痕继痕迹”，英文为“Henjicc”；扩展界面、分类、名称、状态与错误提示均须对应翻译。用户文件名、路径、标签及工作流标题保留原文，内部节点 ID、设置 ID 与 API 路径不随语言改变。
- 宿主设置分类与名称使用 `locales/zh`、`locales/en` 官方翻译入口；自绘图片库文案集中在 `web/picker/i18n.js`，不在业务代码拼接未经翻译的句子。验证中英文切换及现有节点按钮更新。
- 选项、设置、按钮等控件的补充性描述、副标题、说明小字、helper text 或 tooltip，只有用户明确要求时才能在要求范围内新增或扩写。要求新增功能、选项或优化界面，不等于要求增加说明文案。
- 未明确要求时直接省略此类说明，优先用准确标签和合适控件表达用途；不能因“有帮助”“更完整”或“怕用户不理解”自行添加，也不能转移到 placeholder、信息图标或其他位置变相添加。
- 获准添加的说明必须面向产品用户，用简短、自然的语言表达操作、结果或用户关心的后果；不使用开发者口吻，不讲内部协议、算法、日志、技术实现或设计过程。标签已表达清楚的内容不再复述。
- 控件标签、实际运行状态、校验错误和操作结果仍按交互需求提供，并使用面向用户的语言；不能把功能介绍或实现解释包装成状态、错误或提示来绕过上述限制。placeholder 不能替代标签。

## 组件与交互

- 本包自绘面板、节点和浮层的滚动条统一采用细轨道、圆角滑块和透明轨道，沿用宿主主题；样式限定在 Henjicc 界面，不覆盖宿主或第三方面板。资源库样式提供共用规则，标准浏览器使用 thin，WebKit 回退宽度为 6 像素。

- 项目界面禁止使用 emoji、Unicode 符号或 ASCII 字符充当图标，包括选中勾、关闭叉号、星标、目录箭头及按钮装饰；不能通过文字节点、CSS content 或字体字形绕过。统一使用 SVG，优先复用 `web/asset-card.js` 或已安装的 SVG 图标库，不为简单图标新增依赖。装饰 SVG 设置 `aria-hidden`，图标按钮保留中英文可访问名称；检查普通、选中、悬停和禁用状态。真实文案、数值及尺寸乘号等数学内容正常保留，它们不属于图标；用户输入、文件名和素材内容不因这条规则被改写。

- 先搜索已有控件和语义变体，再新增公共组件；不为一次使用过早抽象，也不复制同一控件的行为和样式。
- 展示组件表达数据与意图，业务规则和特权能力通过项目正式入口调用；不因 UI 改动另建平行状态源。
- 交互有可理解标签、键盘路径和可见焦点；加载、空、错误、禁用与成功反馈沿用一致语义。
- 取消、卸载或并发更新涉及异步结果时防止旧结果覆盖新状态；危险动作按可撤销性和授权边界处理。
- 动效帮助解释状态，尊重减少动效偏好；性能问题先测量，再选择虚拟化或缓存等方案。

验证范围由测试规则统一决定。局部文案不触发全部节点的主题检查；共享视觉定义变化才覆盖相关消费者。
