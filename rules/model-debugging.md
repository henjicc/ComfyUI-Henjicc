# 模型适配验证

> 读取时机：本包节点涉及模型输入输出、推理精度、资源预算或适配性验证时。模型选型、下载、采样调优和个人生成任务不属于本仓库默认职责。

## 范围与证据

- 只为当前节点契约选择最小充分验证：注册/schema → 无模型数据流 → 必要的小尺寸真实计算。节点输出验证不能演变为下游模型加载器、量化或采样系统的实现。
- 使用合成素材与隔离执行图，核对真实宿主版本、节点类型、输入输出、shape、dtype/device、尺寸及帧数；不提交个人素材、输出、硬件清单、跑分或宿主绝对路径。
- 重量级编码器可以在数据流测试中替换；该结果只证明转换契约，不证明完整模型可运行或生成质量。需要真实模型时使用当前已安装且兼容的模型，不因测试默认下载权重或改变环境。
- 量化名称、文件存在、加载器枚举或注册成功都不能代替实际计算；遇到缺失输出头、精度/架构不匹配或不兼容内核，应明确归属和失败边界，不修改第三方源码兜底。
- 图片核对原始像素、通道、比例、顺序和参考槽语义；视频核对真实时间戳、帧数、帧率、时长及音画同步；音频按解码 samples 校验长度、采样率、声道及有限值。
- 性能优化必须对应节点自身的真实瓶颈，区分缓存命中、首次加载和实际执行。没有可比证据时不写速度或质量承诺，不把短输入结果外推到长输入。

## 运行边界

- 遵循 [控制操作规程](comfyui-nodes.md#控制操作规程) 和 [验证规则](testing.md)，复用已核验实例，保护用户队列和未保存画布。
- 模型、编码器和 VAE 的运行生命周期沿用宿主；不为适配验证修改 BIOS、驱动、torch/CUDA、内存策略或其他节点依赖。
- 外部请求、费用、用户数据和依赖安装均须在现有任务授权内。只报告实际执行及失败证据，不将模型描述和主观质量结论当作节点计算正确性的替代。
