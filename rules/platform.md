# 宿主插件与平台边界

> 读取时机：改变节点生命周期、宿主集成、系统能力或支持平台时。

- 本项目运行于 ComfyUI Python 后端，由目标宿主管理生命周期；节点 UI 使用宿主画布与控件，不另建网站、窗口系统或独立后端。
- 计算和数据转换必须能经宿主执行 API 运行；前端负责输入和展示，不成为核心执行的必需参与者。
- 注册阶段保持轻量，不启动后台服务、下载模型、发起付费请求或弹出窗口。文件、设备与网络能力遵循宿主及用户实际权限，不将插件当作沙箱。
- Python 要求以 `pyproject.toml` 为准。避免硬编码个人路径、端口或 GPU，不凭单机结果宣称所有平台或 ComfyUI 版本兼容，也不预建未经要求的兼容分支。
- 安装与控制按 [节点规则](comfyui-nodes.md)，实现入口见 [项目上下文](project-context.md)。不接管宿主更新、全局队列和其他节点生命周期。
